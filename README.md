# VetMetro RD - Landing Page SEO Optimizada

Landing page profesional y optimizada para SEO para Clínica Veterinaria Metropolitana.

## 🚀 Características

- ✅ **SEO Optimizado**: Meta tags, structured data, semantic HTML
- 🎨 **Diseño Moderno**: React + Vite + TypeScript + Tailwind CSS
- 📱 **Responsive**: Mobile-first design
- ⚡ **Performance**: Optimizado para carga rápida
- 🎬 **Animaciones**: GSAP y Framer Motion
- 🔒 **Seguridad**: Headers de seguridad configurados
- 🌐 **Deployment Ready**: Configurado para Netlify y Vercel

## 🛠️ Stack Tecnológico

- **Framework**: React 18 + Vite
- **Lenguaje**: TypeScript
- **Estilos**: Tailwind CSS
- **Animaciones**: GSAP + Framer Motion
- **Iconos**: Lucide React
- **Build**: Vite

## 📦 Instalación

```bash
npm install
```

## 🏃 Desarrollo

```bash
npm run dev
```

## 🏗️ Build

```bash
npm run build
```

## 🌐 Deployment

### Netlify

1. Ve a [Netlify](https://app.netlify.com/)
2. Importa el repositorio: `isapromord-eng/vet-metropolitana`
3. Configuración automática detectada desde `netlify.toml`
4. Deploy automático en cada push a main

### Vercel

1. Ve a [Vercel](https://vercel.com/)
2. Importa el repositorio: `isapromord-eng/vet-metropolitana`
3. Configuración automática detectada desde `vercel.json`
4. Deploy automático en cada push a main
